# Guild Found Market 0.18.2

Spread the word about a new version without leaving the changelog.

## Added

**Announce a new version from the changelog overlay.**
The changelog overlay (shown for a newer version, or via `/gfm changelog`) now has an Announce
button at the bottom. It puts a one-line announcement in your chat box: the version plus the short
summary line from the bundled notes, e.g. "Guild Found Market 0.18.2 is out: ... Update on
CurseForge!". You pick the destination first: guild chat, a whisper (with a name box), or any chat
channel you are actually joined to, listed by slot number and name (GFM's own hidden marketplace
channel is excluded). The exact line is previewed in the overlay before you commit, since the chat
box is too small to show it all, and true to GFM style nothing is sent automatically: the button
only prefills the chat line, sending is your Enter. The chosen destination is remembered per
character.
