# Guild Found Market 0.9.2

A bugfix release for the clickable shop links. No protocol or saved-data changes, so it stays compatible with the rest of 0.9.x. Update from CurseForge and run a game restart (or at least `/reload`).

## Fixed

**Shop links no longer interfere with Blizzard's menus.**
To make the "browse shop" links clickable, GFM replaced a Blizzard function, which tainted it and could block protected actions such as "Copy Name" from a right-click menu (an ADDON_ACTION_FORBIDDEN / CopyToClipboard error). GFM now hooks safely instead, so those menu actions work again.

**Shop links work with NovaWorldBuffs and Questie.**
Those addons hook the same link system and tried to show a tooltip for GFM's custom link, throwing "Unknown link type". The shop link is now built as a normal item link (shown briefly, then hidden) that carries the seller name, so it clicks cleanly with those addons installed.
