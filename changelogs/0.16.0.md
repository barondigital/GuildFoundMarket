# Guild Found Market 0.16.0

Shop links get a proper hyperlink type (no more stray Hearthstone tooltip), shop notes can hold
item links with a live preview, and a player's view can toggle between what they sell and buy.

## Fixed

**Shop links no longer flash a Hearthstone tooltip.**
The clickable "browse my shop" link carried a real Hearthstone item as a safe placeholder, so on
some setups its tooltip could stay on screen, on hover, or if opening the shop hit an error before
the placeholder was hidden. The link now uses Blizzard's sanctioned `addon:` hyperlink type, which
raises no item tooltip at all and is handled through a taint-safe EventRegistry callback. There is
nothing to hide, so the stray tooltip is gone by design rather than chased after the fact. The
visible text is shorter too: `[Name's shop]`.

## Added

**Hovering a shop link previews the shop.**
Hover a "browse X's shop" link in chat and GFM shows the seller's name and, when known, their shop
note, in GFM's own styling. The note is pulled on demand (the same request the Sellers list uses),
so it fills in a moment after you hover, without a click.

**Shop notes can list items, with a preview.**
Shift-click an item anywhere to drop its link into the Shop note field (refused cleanly when it
won't fit the note's length limit), and use the new Preview button to see your note exactly as
buyers read it. Notes are shown as written.

**WTS / WTB tabs on a player.**
Opening a seller or buyer now shows WTS/WTB sub-tabs, like My Items, so you can toggle the same
player between what they are selling and what they want to buy. The sub-tabs cross-navigate between
the Sellers and Buyers tabs for that player, and "< Back" returns to wherever you started the
session. Every WTS/WTB tab has a tooltip spelling out Want To Sell / Want To Buy.

## Changed

**A player's note loads on hover.**
The chat-bubble note in the Sellers and Buyers lists now fetches when you hover it, instead of
needing a click. If the fetch fails (the player is offline or paused) it says so, and a click
retries.

**"Selling" is now "WTS".**
The My Items selling sub-tab is renamed to match the new WTS/WTB terminology.

## Not changing

No protocol change. The shop note still travels in its own on-demand reply, the shop announce still
carries only the seller's name, and the WTS/WTB toggle reuses the existing seller-catalog and
buyer-wantlist fetches.
