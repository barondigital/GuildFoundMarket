# Guild Found Market 0.15.2

A small diagnostic for channel owners: see whether anything other than GFM is talking on your
marketplace channel.

## Added

**Channel monitor: `/gfm channelscan`.**
Your marketplace channel is private (its real name is a hash of your channel + password, so it
isn't guessable), but a confederation member who shares the secret can see it, and another addon
could in principle ride it. This command lets you check.

- Run `/gfm channelscan` to start. The Debug view opens and every line that crosses your channel
  without GFM's own tag is logged live as `FOREIGN #n from <player>: <text>`, truncated so a chatty
  addon can't flood the view. GFM's own protocol traffic is only counted, not printed.
- Run `/gfm channelscan` again to stop and print a summary: how long it ran, GFM vs foreign message
  counts, and the busiest foreign senders and message prefixes (so repeated traffic from one addon
  groups together).

It watches the real channel you actually join (matched by the hashed base name, with the joined
index as a fallback), not the configured token or the separate shop-announce trade channel. It is
read-only: it never sends anything, only runs while you have it on, and resets on reload. Output
goes to the Debug sidebar, never to chat.

## Not changing

No protocol or channel change, and nothing new is sent on the wire. The monitor only reads the
channel messages the client already delivers.
