# Guild Found Market 0.17.1

See what's new even before you update, never miss a COD order, and a tidier Options tab.

## Added

**See what's new, even before you update.**
A client can't show the notes for a version it doesn't have yet, so it fetches them from a peer who
does. When a GFM user near you runs a newer version, your client quietly asks them for that version's
changelog and shows it in an overlay each time you open GFM while you're behind, with a clear button
to close it and carry on. Sharing is controlled by a new option, "Share changelog with out-of-date
players" (on by default): while you're on the newest version you answer players who are behind with
your build's bundled notes. Only up-to-date clients answer, so the notes you see always come from
someone actually running that version. Type `/gfm changelog` to read the notes at any time.

**Never miss a COD order.**
An incoming Cash On Delivery request now flashes a short line on screen and prints one to chat, so
you notice it even with the GFM window closed. Orders you add by hand don't notify.

## Changed

**"Accept COD order requests" is now on by default.**

**The Options tab is reorganised.**
Settings are grouped into General, Selling, Cash On Delivery, Shop link visibility, and Updates, each
under its own heading, and the panel now scrolls so there's room for more without crowding.
