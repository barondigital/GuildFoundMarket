# Guild Found Market 0.21.2

Fixes the tooltip Lua error that client 1.15.9 introduced. No functional changes beyond that.

## Fixed

**Tooltip error on client 1.15.9.**
Hovering certain tooltips (the version button, the scan Stop buttons, the COD Send hints and
others) threw `bad argument #5 to 'SetText'`. The tooltip calls passed the wrap flag where the
alpha value belongs; older clients silently ignored the mistake, 1.15.9 validates its arguments
strictly. All call sites now pass the full `r, g, b, alpha, wrap` list, and the long tooltip
texts now genuinely wrap, which was the intent all along.
