# Guild Found Market 0.9.1

A few small improvements to listing prices, plus a large internal cleanup. Nothing changes the wire protocol or your saved listings, and it stays fully compatible with 0.9.0, so guilds running a mix of 0.9.0 and 0.9.1 keep trading together. Grab it from CurseForge and run a full game restart (not just `/reload`), since the addon version and file list changed.

## Added

**Choose how you type prices.**
A new "Price input format" option on the Options tab lets you enter prices either as coins (`3g50s`) or as decimal gold (`3.50`). In the decimal format the two decimals are silver, so `3.05` means 3g 5s. Whichever you pick, search results and seller lists still show the standard coin icons.

## Changed

**Quicker listing edits.**
Editing one of your listings now jumps straight to the price field, and pressing Enter in the quantity or price box places or updates the offer, so you no longer have to click the button.

**Shorter minimap tooltip.**
The minimap tooltip no longer repeats "Listings: online/offline". The icon already dims while you are offline, so that line was redundant.

## Internal

**Codebase cleanup (no behaviour change).**
The addon was refactored for maintainability: the old Core file was split into focused service files (transport, protocol, config, and one file per feature, under a Services folder), the long UI builder was broken into smaller pieces, dead code was removed, and typographic dashes were stripped from the text. None of this touches the wire protocol, your settings, or your listings.
