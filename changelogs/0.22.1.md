# Guild Found Market 0.22.1

Fixes shift-click item insertion, broken by game client 1.15.9, and polishes the Buy tab's
input handling around it.

## Fixed

**Shift-click into the search box works again on client 1.15.9.**
The client update moved Blizzard's own shift-click paths (bags, character tab, chat links)
onto `ChatFrameUtil.InsertLink`. The old global `ChatEdit_InsertLink` that GFM hooked
survives only as a deprecated alias nobody calls anymore, so the hook silently never fired:
no error, just nothing happening. GFM now hooks both the new and the old path (a single
insert only ever passes through one of them), fixing shift-click into the Buy/Buyers search
box and into the shop note box.

**No more stack-split popup on a consumed shift-click.**
When a GFM box takes a shift-clicked stackable bag item, Blizzard's bag handler still falls
through to the stack-split dialog (it only skips the split when the insert reports success,
which a post-hook cannot do). GFM now closes that dialog immediately when it consumed the
click. Stack splitting outside GFM is untouched.

## Added

**Shift-click fills the Browse filter too.**
With the Browse name filter focused, shift-clicking an item inserts its name, since names
are what the filter matches, pre-selected so typing replaces it.

**The Buy tab auto-focuses its input.**
Entering the tab or switching sub-mode puts the cursor straight in the search box (Search)
or the name filter (Browse), with existing text pre-selected so you can type right away.
Picking an item still releases focus, keeping movement keys free after a pick.
