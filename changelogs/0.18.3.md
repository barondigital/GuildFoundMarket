# Guild Found Market 0.18.3

Keeps the version announce away from other addons' hidden channels.

## Fixed

**Hidden addon channels are kept out of the announce picker.**
The version announce on the changelog overlay (new in 0.18.2) listed every channel you had joined,
which included other addons' hidden protocol channels; GreenWall's bridge channel, for one.
Announcing into such a channel made that addon try to parse the line as protocol traffic, producing
"message corruption" errors for everyone on it instead of reaching any players. The destination
picker now only offers channels that are visible in at least one of your chat windows (a channel no
chat window shows is by definition addon wire traffic, not chat), and a previously saved
hidden-channel choice falls back to Guild automatically. Tip for GreenWall confederations:
announcing to Guild reaches all bridged guilds at once.

## Changed

**The shared changelog message is now cumulative per minor.**
A player several patches behind only ever receives the newest build's notes, so the peer-shared
message now compactly covers everything in the current minor (all of 0.18.x) rather than just the
latest patch.
